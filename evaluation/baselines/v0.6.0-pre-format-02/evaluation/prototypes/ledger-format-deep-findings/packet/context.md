# Public Synthetic Request Options

请对 packet.json 声明的修改执行 Deep Review，使用简体中文，严格只读。

这是公开合成的前端请求配置示例。意图是简化参数对象的构造，同时保持
调用方显式传入的参数与返回对象契约。唯一修改路径是 src/options.mjs；
support/src/loaders.mjs 是完整交付且没有改动的直接消费者，通过 options
参数注入本次对比的模块。before 与 after 表示同一逻辑路径的两个完整快照。

requestOptions 接收毫秒整数，接口允许 1500、8000 和 30000，返回对象的
timeoutMs 必须等于传入值。pageOptions 接收分页整数，接口允许 20 和 50，
返回对象的 limit 必须等于传入值。没有默认值变更需求，不要求处理这组
公开契约之外的类型或数值。

fetcher 是调用方注入的演示依赖，接收路径与原始参数对象，并将接收到的
路径和对象作为演示结果返回；不能推断真实定时器、网络请求、服务器、页面
或生产数据的行为。项目没有这两个 helper 的其他消费者，没有重试、认证、
缓存、持久化、生成文件或异步包装。模块内没有未交付的支持实现。
