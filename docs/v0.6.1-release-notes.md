# v0.6.1 Release Notes (Draft)

## 本次修正

Quick / Deep Review 的 Changed-Condition Coverage 偶尔混入解释性正文，
导致报告不符合已有格式。此次明确：

- Coverage 内只放条目和空行，解释或限制放到 Evidence。
- 每个条目的 Disposition 只输出一个最终状态。
- Fix Review 保持针对既有问题的回审，不增加 Coverage ledger。

只修改核心说明和 Quick/Deep 两份模式参考文件。其余九个安装文件保持原样，
包括 Fix 参考文件、collector、框架参考和元数据。严重级别、Origin、
Reproduction、问题合并规则、中文标题、只读边界和提交建议规则保持不变。

这属于已有契约的格式修正，依据[版本规则](versioning.md)准备为 v0.6.1 候选版。
未新增 File Coverage、复现概率估算或审核模式，也未进行规则压缩。

## 验证与限制

- 正式应用后的完整工作区检查：1,699/1,699，81 个测试文件，无跳过；
  两个 Skill 结构校验器通过，12 个安装文件与已验收候选一致。
- 已有公开合成运行时证据：一个 Quick、两个不同 Deep 场景，分别覆盖
  非空问题、缺失目标的 Cannot Verify、重复 Finding-ID 的正确表达。
  沿用原始报告和人工判断，不计作新的模型审核。
- 新增一次当前候选的 [O-09 Fix 验收](evaluation-results/v0.6.1-codex-fix-runtime.md)：
  Codex Desktop / gpt-6-astra / xhigh，用时约 161 秒；材料读取、输出格式和
  十项语义检查通过，保留问题来源及修复前后观测，Fix 未扩展成 Deep。
- 更新后的 876 文件独立交付目录通过 1,699/1,699 项检查和两个结构校验器；
  后续全新目录另完成锁文件依赖安装：下载 45 个包、复用 0 个包，并再次
  通过完整测试和两个校验器。首次缺少原生包的安装记录保留，Python/PyYAML
  仍复用现有环境。这不是公开 tag 下载或新增客户端运行时验收。维护材料
  随仓库保留，实验能力不进入安装 Skill，详见[发布准备](v0.6.1-release-preparation.md)。
  Vitest 与结构检查不证明 AI 的一般准确率或真实业务效果。
- 本次没有新增英文输出、Cursor/Claude、自动触发或正式安装流程的
  运行时验收，不能沿用 v0.6.0 的客户端标签宣称新版全部验证通过。
- Quick/Deep 每次所选说明增加 556 字节，Fix 所读核心增加 325 字节；
  这些是字节差异，不是 token、延迟或费用改善。

历史测试改为读取冻结输入，避免后续 Skill 修改破坏旧评测的可复现性。
这些维护文件不会进入安装的 Skill 目录。历史 File Coverage 实验和失败记录
仅作为可追溯资料保留，独立 runtime harness 仍为 `runtimeReady=false`。

## 使用与交付状态

普通 Markdown Skill 使用仍只需要兼容的客户端和可读取的审查材料，无需
安装 Vitest、Node.js 或 PyYAML。读取仓库 diff 需要 Git；使用可选上下文
收集器或输出校验器需要 Node.js，仓库测试和结构校验使用维护依赖。
本次没有新增使用依赖。
