## Source-free Gate

The probe workspace contains no source, Skill, oracle, or prior result. It is an empty non-Git directory, so freeze `--skip-git-repo-check` as a source-free-only flag instead of discovering that requirement through a failed model attempt. Send exactly:

```text
Return exactly CLIENT_ISOLATION_OK and nothing else. Do not use tools.
```

Require exit 0, one completed turn, one final message equal to `CLIENT_ISOLATION_OK`, zero tools/MCP, no unexpected context, and no workspace mutation. Compare final-message content from JSONL, treating the output file's terminal newline only as serialization; retain raw bytes and hashes. Deadline: 120 seconds, one invocation, no request/stream retry. Retain stderr; unexplained configuration, isolation, authentication, or transport warnings stop the window. The PATH-alias warning seen in local help/version checks is not preapproved runtime stderr.

A pass shows only connectivity and the observed no-tool response under that frozen setup. It neither proves source-bearing read isolation nor review quality, and does not authorize source transmission. Review invocations can contain multiple model/tool turns; one probe plus seven reviews is a maximum of eight CLI invocations, not eight billable API requests.

## Quality And Stop Gates

Score each result before proceeding to the next run. Required order: execution/completion -> scope and write safety -> output structure -> source-backed semantic judgment -> repeat consistency when applicable. Invoke the public `validate-review-output.mjs --mode quick|deep|fix` CLI, not its internal strict module. Correlate the saved Markdown with the final assistant message in JSONL. Use `audit-runtime-trace.mjs` as one check and independently verify expected collector counts, failed commands, unsupported tools, outside reads, and complete workspace/Git integrity; its general allowlist is not this window's full policy.

- Required-finding recall = matched required independent findings / required findings. Precision = evidence-supported actionable findings / all actionable findings. Severity accuracy = correctly classified findings / adjudicated findings. Each applicable metric must be 100%; an empty denominator is `N/A`, not an invented 100%. Record numerators and denominators per run, not only pooled totals.
- Validate the actual source paths, original trigger, impact, root cause, minimal repair, verification suggestion, and before/after evidence. Unsupported extra findings fail precision; additional genuinely evidenced findings require explicit semantic adjudication and are not automatically false positives just because the seed oracle lacks them.
- Preserve the original oracle files. The explicit evaluator-only overlay for D-ID-001 requires `Blocking` with canonical `Login/Auth Failure`, preserving Candidate 16's counter-regression gate. The older oracle permits Risk too; that historical contract is not rewritten. Q-ID-002's ignored-timeout finding remains Risk only. Never transmit either grading requirement in the Prompt.
- Quick/Deep require independent sequential IDs, the complete physical one-line Coverage grammar, consistent merge keys on repeated IDs, and no invented merge key requirement for a single ID. A valid parser result cannot prove that all changed conditions were covered or that merged conditions share an indivisible repair; adjudicate these against the diff.
- Preserve localized scope, headings, conclusion, recommendation, design decision, naming/readability, module boundaries, and evidence limits required by the chosen mode. Do not force Deep-only fields into Fix. Fix preserves all three original IDs/severities and exactly one Resolved status each, checks only direct repair/regression paths, reports no new regression, and recommends 可以关闭. K-ID-001 requires zero actionable findings, Keep, and 可以提交.
- Require no model writes or write attempts, no forbidden tools/paths, no unexpected context, complete trace correlation, expected deterministic test results, and unchanged workspace/Git state. Seeded negative tests are supposed to fail; distinguish their expected assertions from execution/environment failures. Completed test-assertion failures, valid search no-match results, and diff-check results are review evidence, not tool unavailability. Launch failures, permission denials, timeouts, incomplete output, or scope conflicts stop the window.
- Review timeouts are 900 seconds for Quick/Fix and 1800 seconds for Deep. Record elapsed time and available input/cached-input/output tokens; record unavailable counters as unavailable. They are observations, not acceptance substitutes or a general Skill-efficiency benchmark.

The first failure stops all remaining runs. A scored quality or safety failure is `No-Go`; missing runtime evidence is `Cannot Verify`; an invalid or contaminated evaluation is `Cannot Score`; cancelled runs are `Not Run`. No in-place retry, replacement, mode/provider switch, Prompt repair, oracle relaxation, or Skill edit is permitted inside this window. Preserve raw failures. A suspected evaluator bug may receive a separately authorized offline replay of the saved trace with both old and new judgments retained; it never justifies a hidden new model call.

Completion requires the source-free gate plus 7/7 source-bearing runs passing every applicable gate. Report the exact client/model/configuration and fixture scope, not universal Codex compatibility or production reliability. These cases have no browser-observable workflow: Playwright is not applicable, Context7 remains prohibited, and browser/WebView/Native/backend/production behavior remains unverified.
