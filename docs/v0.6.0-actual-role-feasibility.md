## Official Interface Evidence

The fetched [Developer commands](https://learn.chatgpt.com/docs/developer-commands?surface=cli) and [Codex App Server](https://learn.chatgpt.com/docs/app-server) pages establish the following documentation claims:

- `codex app-server` supports JSONL over stdio; the initialization handshake is `initialize` then `initialized`.
- The app-server page states that it starts a local Code Mode host by default. `--code-mode-host` instead selects a shared remote host connection. This plan keeps the selected local host.
- `command/exec` accepts an argv array and executes under the server sandbox without creating a thread/turn. The docs do not establish that this method routes through the selected Code Mode host or is equivalent to `codex exec`.
- The docs provide app-server subcommands for generating version-specific TypeScript/JSON schemas. Installed-version support remains to be verified; generated output would prove schema shape, not execution routing or isolation.
- `process/spawn` explicitly runs outside Codex's sandbox and is experimental. It is not the selected diagnostic route.
- App-server is experimental. `--sandbox` describes model-generated command policy, and `--ignore-user-config` does not disable authentication reads by itself. Isolated directories and outer file/network limits are still required.

Both fetched text bodies are truncated; exact selected excerpts are retained locally with offsets, URLs and retrieval limitations. A bounded search returned no indexed result before the direct pages were fetched. These sources identify a plausible interface; they do not prove absence of other interfaces or current installed-binary behavior.
