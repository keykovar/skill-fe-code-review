## Scope

Each source-bearing client run used a fresh public synthetic URL-regression fixture containing the release Skill and adapter files. No private project source, credentials, evaluator oracle, historical trace, or provider endpoint was transmitted.

The Quick oracle required three independent Findings:

1. A tracked change imports an untracked `src/request-config.ts` file (`Blocking`).

Accepted recommendations were `修改后提交` or `不建议提交`. Semantic recall, severity, output structure, one-time collector use, trace isolation, read-only behavior, and workspace integrity were independent gates. A run is not a post-release runtime pass unless every applicable gate passes.

## Operational Findings

- Cursor Ask mode can keep the final response in chat and preserve repository files, but the inspected client version cannot execute the mandatory shell collector under this invocation. Its file-tool fallback is not equivalent to the accepted all-uncommitted review procedure.
- Repeated denied collector attempts and reads of client session state violate the frozen trace contract even when semantic findings and workspace hashes pass.
- Switching to Cursor Plan mode after observing the failure would create a replacement sample and can route output through a write-capable plan tool. No such replacement run was performed.
- A source-free probe establishes client isolation only. It is not model-quality evidence and does not authorize a source-bearing request by itself.

## Evidence Boundaries

- The fixture is public and synthetic. It validates seeded-finding recall, severity, Finding identity, recommendation consistency, output structure, collector discipline, read-only behavior, and trace isolation. It does not measure general precision or production framework behavior.
- Raw traces, temporary paths, login identifiers, credentials, provider endpoints, and evaluator-only oracle files are excluded from this report.
- The trace auditor detects explicit tool requests and paths; it is not an operating-system sandbox. Before/after Git status and file hashes remain required evidence.
- Playwright was skipped because the fixture has no browser-observable product path.
- No WebView, Native bridge, physical device, backend, deployment, monitoring, or production environment was exercised.
