# v0.1.0 Evaluation Results

Evaluation date: 2026-07-23
Release: [`v0.1.0`](https://github.com/keykovar/skill-fe-code-review/releases/tag/v0.1.0)
Release commit: `b9e1d71423aafa53aadb58da4394de2df5a92b56`

## Method

A synthetic TypeScript Git repository was used for a repeatable Quick Review smoke test. The working tree contained:

- One modified tracked URL helper.
- One untracked configuration file imported by the tracked helper.
- An existing caller and test that exposed a removed slash-normalization behavior.

The prompt requested Quick Review in Simplified Chinese and explicitly required read-only behavior. Client output was judged against the expected findings and the post-review Git status.

Manual pre-release acceptance had also exercised Codex Quick, Deep, and Fix Review on real repository changes. Those runs validate workflow shape but are not included in the repeatable fixture metrics because their source diffs are private and mutable.

## Expected Findings

1. A tracked file imports an untracked file. Expected severity: `Blocking` because clean checkout and CI cannot resolve the module.
2. Removed URL slash normalization changes observable output. Expected result: report as material `Blocking` or `Risk`, explain the before/after behavior, and reject an unconditional submit recommendation.

The Cursor run reported `Worked for 42s` in the client UI. This is an observation, not a performance target, because duration depends on the model, client, machine, and repository state.

## Notable Output Differences

- Codex classified the slash-normalization regression as `Risk`; Cursor classified it as `Blocking`. Both explained the changed behavior and rejected submission.
- Cursor additionally identified that a generic URL builder should not silently default to a profile-specific path. This was accepted as a defensible design finding, not part of the seeded finding count.
- Both clients disclosed that Vitest was not executed because the synthetic fixture had no installed test dependencies.

## Read-Only Evidence

Before and after each runtime review, `git status --short` remained:

```text
 M src/url.ts
?? src/request-config.ts
```

No review modified files, installed dependencies, changed branches, committed, or pushed.

## Limitations

- The fixture measures whether seeded issues are found; it does not provide a general precision or false-positive score.
- Deep and Fix Review were not repeated in Cursor for this release.
- Claude Code runtime behavior remains unverified.
- No browser, real network, framework runtime, or production release path was exercised by the synthetic fixture.
- Model output can vary. Compatibility should be rechecked after client, model, adapter, or public workflow changes.
