## Prototype Grammar

Inside each recognized Finding, require exactly one origin nested bullet labelled `Origin`, `问题来源` or `问题来源 / Origin`, and one reproduction nested bullet labelled `Reproduction`, `复现观测` or `复现观测 / Reproduction`. These aliases identify the same two fields; mixing aliases does not permit duplicate fields. Use a stable English state name, optionally its Chinese translation, followed by substantive evidence prose. An enum or its translated label alone is insufficient. Missing, duplicate, orphaned, or fenced-only fields fail.

```md
  - 问题来源：New：本次引入；比较基线有版本保护，当前分支移除了保护。
  - 复现观测：Observed：已观测；本地 Node 合成场景共2/3次失败；证据为 mixed-current 逐次记录。
```

Each Observed group requires exactly one non-negative integer `n/N` with `N > 0`, `n <= N`, safe integer bounds, and accompanying context/evidence prose. Signed, fractional, missing, duplicate and out-of-range counts fail. Other states must not invent a count. Different groups use distinct context labels and ` | ` separators, for example:

```md
  - Reproduction: [pre-fix] Observed - 1/1 local Node URL trial failed; evidence O-09 before record. | [post-fix] Cannot Verify - equivalent WebView environment is unavailable.
```

This prototype rejects numeric percentage literals in the two fields, including full-width forms and numeric Chinese percentage wording. It also rejects negated percentage literals: write a non-numeric limitation such as "not a production probability" instead. This is a deliberately limited prototype grammar, not a new restriction installed in the current Skill. It does not attempt to parse every natural-language probability claim or infer units and provenance from prose.

Fix New Regression accepts only New or Amplified attribution. Previous Findings retain a separate origin field and support Unknown without automatically changing closure. This validator cannot itself prove that the correct original/fix baseline was used.
