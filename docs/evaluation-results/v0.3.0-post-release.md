## Scope

The public tag was cloned into an isolated temporary directory. Dependencies were installed from the release lockfile, and each source-bearing run used a newly generated Quick fixture with project-local Skill copies. Only the repository's public synthetic URL helper was sent to the configured model services; no private project source, credentials, evaluator oracle, raw historical trace, or provider endpoint was transmitted.

The expected findings were:

1. A tracked change imports an untracked `src/request-config.ts` file (`Blocking`).
2. Slash normalization was removed and the deterministic test fails (`Blocking` or `Risk`).
3. The public `baseUrl` parameter is ignored (`Risk`).

Accepted recommendations were `修改后提交` or `不建议提交`. Semantic recall, severity, final-output contract, context-collector discipline, trace policy, workspace integrity, and client isolation were independent gates. A run is not a runtime pass unless every applicable gate passes.

## Operational Findings

- Cursor plan mode in CLI 2026.08.11 can force a review through `createPlan` despite the Skill's chat-only contract. It is not an acceptable read-only review mode for this release.
- Cursor ask mode avoids `createPlan`, but in this run it could not execute the required shell-based Git and test evidence. It is not equivalent to the accepted Quick Review procedure.
- A normal user-level Skill install can be auto-discovered in addition to the fixture-local Skill. A temporary home prevents that discovery, but isolated authentication requires Cursor's `AGENT_CLI_CREDENTIAL_STORE=file` mode.
- Cursor CLI changed from the version observed before the initial run to 2026.08.11 during the evaluation period. Because the initial trace does not embed the CLI version, its exact binary version remains `Cannot Verify`.
- Codex emitted MCP shutdown and local state-database warnings on stderr. The accepted trace contained zero MCP calls; these warnings are client-environment observations rather than review evidence.

## Evidence Boundaries

- The fixture is synthetic and validates seeded-finding recall, severity, recommendation, output structure, collector use, and read-only discipline. It does not measure general model precision or production framework behavior.
- Token counts and elapsed time are client/model observations, not Skill-only benchmarks.
- The trace auditor detects explicit tool requests and paths; it is not an operating-system sandbox. Before/after Git state and relevant file hashes remain required.
- Raw traces, temporary paths, login identifiers, credentials, provider endpoints, and evaluator-only oracle files are excluded from the repository report.
- Playwright was skipped because the fixture exposes no browser-observable path.
- No WebView, Native bridge, physical device, backend, deployment, monitoring, or production environment was exercised.
