## Scope

This patch candidate adds deterministic Cursor Agent `stream-json` trace auditing and clarifies one minimal-sufficient-design classification. It does not add a review mode, output section, Finding field, or installation path.

The auditor rejects direct oracle reads, direct path requests outside the generated fixture workspace, write tools, common write-capable shell commands, and file-output redirects. Before/after Git status and relevant file hashes remain the final write-safety evidence. Trace integrity, unchanged files, semantic-oracle matching, and deterministic fixture behavior are independent acceptance gates.

- Trace inspection catches explicit tool and shell requests; it is not an operating-system sandbox and cannot prove that arbitrary executed code has no hidden reads or writes.
