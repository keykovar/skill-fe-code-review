# v0.2.0 Candidate Evaluation Results

Evaluation date: 2026-07-31
Release candidate: `v0.2.0`
Comparison baseline: stable `v0.1.1` at commit `28c2323`

## Change Classification

v0.2.0 is a minor candidate because it materially extends the public review contract while preserving the existing Quick, Deep, and Fix mode names, required top-level sections, severity labels, read-only default, and install layout.

The candidate adds or changes:

- Evidence-backed minimal sufficient design decisions for Quick and Deep Review.
- A documentation-tool contract that prohibits direct or indirect Context7 use during code review.
- Optional browser runtime evidence with explicit safety, reproducibility, redaction, and mode-budget gates.
- Explicit `Cannot Verify` semantics for Quick/Deep evidence, Fix closure, and design decisions.
- A strict Fix Review versus Deep Review boundary.
- A single recommendation contract that keeps the conclusion, severity gates, and final recommendation consistent.
- Complete Deep and Fix scope ledgers and stronger bilingual and compatibility contract tests.
- An explicit chat-only output boundary for review and evaluation requests, including Cursor Agent and Build modes.
